# Дорожная карта CV-Agent

Состояние на 20.08.2026.

## 1. Цель и рамки

Цель проекта — надёжный локальный многопрофильный агент для поиска вакансий,
оценки соответствия кандидата, подготовки немецкого Anschreiben и сборки
досье для ручной отправки.

Целевая модель:

- данные, документы, ключи, задания и досье каждого семейного профиля не
  смешиваются;
- профили свободно переключаются через UI без паролей;
- локальная Ollama является основным LLM-провайдером;
- отправка персональных данных внешнему LLM выполняется только через
  разрешённую сервером конфигурацию и с понятным пользователю уведомлением;
- поиск и LLM-задачи выполняются в восстанавливаемой фоновой очереди;
- результат scoring воспроизводим: сохраняются модель, версия prompt,
  причины оценки и версия текста вакансии;
- приложение остаётся полуавтоматическим — отправку заявки выполняет человек.

Проект предназначен для запуска на `127.0.0.1` и использования владельцем и его
семьёй. Профиль — это средство разделения вакансий и файлов, а не граница
конфиденциальности между членами семьи. Пароли, роли и запрет намеренного
переключения на другой семейный профиль не входят в scope. Если приложение
когда-либо потребуется открыть в интернет или недоверенную сеть, полноценную
аутентификацию следует проектировать как отдельный этап до такого открытия.

## 2. Правила выполнения дорожной карты

- Приоритеты: **P0** — безопасность/потеря данных, **P1** — ошибки основного
  сценария, **P2** — надёжность и эксплуатация, **P3** — улучшения качества.
- Каждый этап завершается только после выполнения его exit gate.
- Изменения схемы и файловой структуры сначала получают резервную копию,
  dry-run миграцию и тест отката.
- После каждого этапа выполняется полный `.venv/bin/pytest`.
- Новая функциональность не должна читать production DB, реальные CV или
  `data/llm.lock` во время тестов.
- Секреты и персональные данные не выводятся в логи и тестовые fixtures.

## 3. Целевые релизы

| Релиз | Результат | Состав |
|---|---|---|
| `0.2` | Безопасный локальный web UI | Этапы 0–2 |
| `0.3` | Корректный document/score/search pipeline | Этапы 3–4 |
| `0.4` | Надёжные фоновые задания и досье | Этапы 5–6 |
| `1.0` | Воспроизводимая установка и эксплуатация | Этапы 7–8 |

Ориентировочный общий объём: 25–41 инженерный день. Оценка не включает время на
ручную проверку изменившейся HTML-разметки StepStone/LinkedIn/get-in-it.
