# ADR-003: поэтапная поддержка форматов документов

- Статус: Accepted
- Дата: 20.08.2026

## Контекст

UI заявляет PDF, DOC, DOCX, TXT, MD, ODT и RTF, но текущий extractor передаёт
любой файл в pypdf. Не-PDF документы молча не участвуют в keywords, scoring и
Anschreiben.

## Решение

Для релиза `0.2` гарантированно поддерживать:

- PDF с текстовым слоем через pypdf;
- UTF-текст и Markdown с определением/валидацией encoding.

Дальнейшие форматы:

- DOCX и ODT — только через отдельные безопасные extractors и fixtures;
- RTF — после выбора ограниченного parser без выполнения embedded content;
- legacy DOC — отклонять, пока не появится изолированный converter с timeout,
  лимитами памяти/размера и тестами повреждённых файлов.

Upload принимает только форматы, которые реально поддерживает активный registry.
Для каждого документа сохраняются type, size, hash, результат извлечения и
понятная ошибка. PDF без text layer помечается как требующий OCR; OCR не входит в
первую реализацию.

## Последствия

- UI перестаёт обещать несуществующую поддержку.
- Добавление формата становится изолированным изменением registry.
- Некоторые существующие DOC/RTF потребуется преобразовать в PDF/DOCX/TXT.
