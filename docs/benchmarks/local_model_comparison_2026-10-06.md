# Локальное сравнение эмбеддингов, 06.10.2026

На небольшом синтетическом наборе Qwen3 и BGE-M3 дали то же качество, что
словарные правила. Оснований менять модель, пороги или default engine пока нет.

Набор: scoring_tasks_seed.yaml, 5 вымышленных профилей × 12 вакансий = 60 пар.
40 пар используются для настройки, 20 отложены. Ожидания сценариев заданы
отдельно от расчёта; ручной проверки реальных вакансий они не заменяют.
Алгоритм: algorithmic.v3, min_score=70, k=3.

| Показатель | Qwen3 Embedding 0.6B | BGE-M3 |
|---|---:|---:|
| Первый прогон, пустой кэш векторов | 11.38 с | 23.72 с |
| Повторный прогон, кэш в памяти | 0.092 с | 0.093 с |
| Запросы первого / повторного прогона | 196 / 0 | 196 / 0 |
| Новые векторы первого / повторного прогона | 114 / 0 | 114 / 0 |
| Resident size после первого прогона | 2 370 652 077 байт | 664 000 265 байт |
| Предложенный cosine-интервал на calibration | 0.45–0.85 | 0.45–0.95 |
| Предложенный min_score на calibration | 70 | 70 |

Resident size и size_vram совпали: этот запуск использовал GPU. Поля получены
из [Ollama /api/ps](https://docs.ollama.com/api/ps); это моментальный размер
загруженной модели, а не пиковая RAM процесса, размер установки или CPU-замер.
«Первый» означает пустой кэш векторов; модель могла быть загружена ранее.
Повтор использует MemoryVectors, а рабочий сервис — SQLite.

На holdout у словарного baseline и обеих моделей при исходном пороге 70:
TP=4, FP=0, FN=0, TN=16; unscored=0. Macro Precision@3=0.2666,
Macro NDCG@3=1.0; precision/recall/F1 по всем парам = 1.0. Низкий Precision@3
объясняется тем, что подходящих вакансий меньше трёх на профиль. Macro-метрики
усредняют только определённые значения: профили без подходящих примеров могут
не иметь F1/NDCG. Это очень простой контрольный набор, не подтверждение качества
реальной выдачи. Предложенные пороги дают те же решения на holdout; настройки
criteria.yaml не изменены, LLM-сравнение на этом наборе ещё не выполнено.

Полные результаты, исходные сходства, digest и перебор порогов:

Воспроизведение: `bash scripts/compare-local-embeddings.sh` (скачивает модели).

Qwen использует инструкцию для query, BGE-M3 — без префиксов. Размерность обеих
моделей в этом запуске — 1024, num_ctx=4096. Лицензия исходной Qwen — Apache 2.0,
BGE-M3 — MIT; настройки основаны на официальных карточках
[Qwen](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B) и
[BGE-M3](https://huggingface.co/BAAI/bge-m3).
